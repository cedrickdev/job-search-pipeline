# Job Search Pipeline — V2

Job Search Pipeline is evolving from a personal job-search automation tool into a multi-user autonomous career opportunity platform.

The V2 supports:

- full-time and part-time jobs;
- student jobs;
- internships;
- apprenticeships / alternance / work-study programs;
- graduate programs;
- temporary and freelance opportunities where enabled.

The system discovers opportunities, evaluates fit and eligibility, generates evidence-grounded ATS-compatible application material, applies through supported channels, tracks outcomes, prepares interviews, and learns from results.

## Implementation rule

V2 must be implemented incrementally. Every roadmap phase ends with:

1. tests and checks;
2. a summary of changed files;
3. risks and migrations;
4. explicit request for user validation;
5. **STOP** until the user explicitly approves continuation.

Do not implement multiple phases in a single run.
